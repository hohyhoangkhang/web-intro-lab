Internet và World Wide Web

Internet là một hệ thống mạng máy tính toàn cầu, kết nối hàng tỷ thiết bị với nhau thông qua các giao thức truyền thông. Internet là nền tảng hạ tầng, cho phép truyền tải dữ liệu giữa các máy tính trên khắp thế giới.

Web (World Wide Web) là một dịch vụ chạy trên Internet, cho phép người dùng truy cập các trang web thông qua trình duyệt. Web sử dụng giao thức HTTP/HTTPS và ngôn ngữ HTML để hiển thị nội dung.

    Internet là hạ tầng mạng, Web là dịch vụ chạy trên đó

    Web sử dụng giao thức HTTP để trao đổi dữ liệu

    Trình duyệt là công cụ giúp người dùng truy cập Web
